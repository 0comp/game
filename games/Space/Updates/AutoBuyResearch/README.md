# Auto Buy research update

Changes to the current ORBIT Studio version, which includes the newer shop and monetization modules.

- Auto Buy requires BOTH eight unlocked worlds and a single-level research purchase for 500,000,000 Energy.
- Buying it enables automatic RESEARCH purchases immediately. It never buys producers or permanent upgrades.
- Each second, it buys up to one affordable level per research track in catalog order, skipping the Auto Buy unlock itself.
- The toggle in Research turns it on or off after purchase.
- The Auto Buy unlock and on/off setting survive Ascend. Other research levels reset normally.
- Owning eight worlds makes the research available; it does not grant Auto Buy without payment.
- The before folder contains the three original Studio sources.
- The before-research-only folder preserves the paid producer-auto-buy version before this change.

These files are source copies of the update, not a complete game package. Existing release ZIPs and the clean template predate the latest Studio expansion. Publish the current ORBIT Studio project to include its latest changes.
