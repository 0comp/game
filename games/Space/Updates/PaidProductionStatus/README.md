# Paid production status

The existing top-right banner now shows the Double Production pass as well as timed paid boosts.

- Double Production pass only: DOUBLE PRODUCTION PASS: x2.
- Timed boost only: PAID x2 with a countdown.
- Both: PAID PRODUCTION x4, plus a separate line showing the pass, timed multiplier and countdown.
- When a timed boost expires, an owned Double Production pass continues to display x2.

The indicator reads server snapshots. It does not grant purchases or change reward calculations. The game layout scale is unchanged.
